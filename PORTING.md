# Compositor → CompositorLX parity tracker

The macOS implementation and its tests are the behavioral specification. Work is ordered so later tools share the same document, history, raster, and persistence foundations.

## Foundation

- [x] Project reader and layer renderer
- [x] Document history with nested transactions and bounded snapshots
- [x] Core layer commands: create, add, delete, rename, visibility, reorder, duplicate
- [x] Layer hierarchy: folders, descendants, grouping, placement
- [x] Connect every editor command to `EditorSession` (menus, shortcuts, layer panel, tool controls, and transform fields)
- [x] Project writer, timed autosave, atomic Save/Save As, untitled recovery, recovery prompt, and dirty replacement/close handling
- [x] New canvas and image import
- [x] Workspace tabs and dirty-state close handling (non-modal New Canvas tabs with an embedded clipboard-aware creation screen, independent documents/history, tab switching, cross-project layer-tree copying with remapped identities and independent undo, targeted tab drops, one-new-tab-per-image drop behavior, and close confirmation)
