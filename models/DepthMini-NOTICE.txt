DepthMini depth model (models/depthmini.onnx)

DepthMini is macOS Compositor's depth model for Volumetric Light, by Robbie Tilton, published at
https://github.com/robbietilton/Compositor/releases/tag/depth-model-1 as a Core ML package. It is a 2.6 MB model
distilled from Depth Anything V2 Small (Apache License 2.0, https://github.com/DepthAnything/Depth-Anything-V2) and
uses parts of torchvision (BSD 3-Clause License, https://github.com/pytorch/vision).

CompositorLX ships the same network converted from that Core ML program to ONNX by scripts/convert-depth-model.py:
the same layers and weights (its 6-bit palettized weights kept as indices into their tables), run in 32-bit floats.
